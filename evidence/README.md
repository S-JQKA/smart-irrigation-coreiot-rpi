# Evidence

Evidence sẽ được quản lý theo `run_id` và liên kết với FR/NFR/test case.

```text
manifest/
runs/<run_id>/
curated/report/
curated/slides/
physical/
```

Mỗi kết quả phải ghi rõ mức kiểm chứng `DESIGN`, `SIM`, `SIM+PLATFORM`, `HIL` hoặc `PHY`, cùng thành phần thật và thành phần mô phỏng.
